# Input

Campo de texto com label, erro e suporte a atributos Livewire.

## Uso

```blade
<x-sampaui::input
    name="email"
    label="Email"
    placeholder="voce@empresa.com"
    wire:model.live="email"
/>
```

## Props

- `type`
- `label`
- `name`
- `value`
- `placeholder`
- `error`
- `disabled`
